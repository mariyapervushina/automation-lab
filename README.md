# README для локального запуска n8n через Docker

Для начала работы по первому этапу Контура А, автоматизации

---

## Команда для терминала

```
docker run -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n
```

---

## Флаги -p, - v

Флаг -p - означает port, т.е. с помощью переброса портов мы создаем "трубу" из нашего внешнего порта во внутренний порт, порт контейнера, флаг -v - означает volumes, с помощью этих томов данные изначально лежат в папке на Mac, а контейнер просто в неё смотрит/пишет напрямую; поэтому удаление контейнера их не трогает — они никогда не были внутри него.
